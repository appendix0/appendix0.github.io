PincerCraft

A harness for open-world, long-horizon agents

Independent project · 2026

Built on Mindcraft and inspired by Voyager. I developed multistep planning, refreshed world-state feedback, action checks, and an evaluation system around an LLM, reusing the existing action functions.

On a fixed 13-task Minecraft benchmark, false completion occurred in 2/52 attempts with the full harness and 23/51 without its experimental components, using the same model.

Memex

Shared memory and associative trails for AI agents

Independent project · 2026

Inspired by Vannevar Bush’s As We May Think, I built a shared knowledge system to address context scattered across multiple agents’ separate memories. It preserves findings and associative trails describing how ideas and decisions developed.

I use and iterate on it across my ongoing projects, retrieving prior context across agent sessions.
